# PMU Data Automation System

## Overview
This project automates PMU validity report generation using Python.

The tool:
- Reads PMU log/text files
- Extracts PMU IDs
- Calculates validity percentage
- Generates date-wise Excel reports automatically

## Features
- Dynamic Input Folder
- Automatic Output Generation
- Date-wise Excel Reports
- Portable Automation Workflow

## Technologies Used
- Python
- Pandas
- Excel Automation
- File Handling
